The General BIOS Laboratory exists to convert frozen scientific protocols into reproducible experimental reality without allowing execution infrastructure to acquire adjudication, interpretation, repair, or promotion authority.

```text
Protocol
  -> Executable Bindings
  -> Binding Hash
  -> Hermetic One-Shot Run
  -> Raw Residue
  -> Immutable Evidence Package
  -> Independent Chamber Ingress
  -> Scientific Adjudication
```

## Governing Laws

1. Execution Authority != Adjudication Authority.
2. Recovery Authority != Genesis Authority.
3. Related Artifact != Bound Experimental Referent.
4. No downstream stage may repair an upstream deficiency.
5. No residue, no adjudication.
6. Protocol completeness grants permission to experiment, not permission to conclude.
7. Recomputation may verify a historical commitment; it may not create one.
8. Maneuverability may increase while scientific standing remains stationary.

## Laboratory Jurisdictions

- `bindings/` — material executable referents and binding manifests.
- `protocols/` — frozen experimental protocols; immutable once execution begins.
- `runners/` — hermetic deterministic execution machinery.
- `residue/` — raw execution outputs and hash roots; no narrative adjudication.
- `ingress/` — independent byte-level verification contracts.
- `adjudication/` — Chamber-facing result records; execution code has zero write authority here.
- `genesis/` — prospective material genesis lineages explicitly authorized when recovery is exhausted.
- `registry/` — laboratory state, experiment identity, hashes, lineage and transition eligibility.
