## Constitutional law

`Declared Client Facts != Authenticated Client Facts != Admission Eligibility != Execution Jurisdiction`

`Unable To Verify != Permission To Infer`

Each fact resolves to one typed state:

`AUTHENTICATED | CONTRADICTED | UNRESOLVED | EXPIRED | NOT_APPLICABLE`

Authentication answers only whether a declared fact is externally supported. It does not decide admission or execution.

## Authentication witness

`W_F = <I_F,F,E,P,tau,R>`

- I_F: fact identity
- F: declared fact
- E: external evidence
- P: provenance/evidence pointer
- tau: authentication epoch
- R: typed authentication result

`AuthenticationWitness != AdmissionDecision`.
