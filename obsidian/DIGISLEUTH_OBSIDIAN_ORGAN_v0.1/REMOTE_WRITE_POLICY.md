# REMOTE_WRITE_POLICY_v0.1

## Default operating posture

Founder-authorized AI implementation SHOULD prefer remote, traceable file writes over manual copying when a writable execution substrate is available.

## Governing chain

`Founder Objective -> Bounded AI Execution -> Git Commit -> Local Pull/Sync -> Obsidian Projection`

## Required preconditions for each write

1. Resolve current branch head.
2. Identify exact target object(s).
3. Preserve object identity and authority boundaries.
4. Refuse to infer missing evidence or permissions.
5. Produce auditable file-level lineage.
6. Keep representation surfaces non-sovereign.
7. Preserve rollback and historical failure states.

## Prohibitions

- no force rewrite merely to clean history;
- no authority promotion from Markdown existence;
- no synthetic evidence creation;
- no execution rights inferred from Founder preference alone;
- no downstream repair of upstream deficiency.

`Automated Writing != Automated Authority`
