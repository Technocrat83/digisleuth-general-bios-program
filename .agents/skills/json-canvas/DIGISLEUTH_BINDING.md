## Write protocol

For every Founder-authorized AI Canvas write:

1. Resolve current Git branch head.
2. Read source Markdown objects and current `.canvas` state.
3. Establish the exact authorized projection delta.
4. Preserve existing object identity and Canvas IDs where the object persists.
5. Generate new 16-character lowercase hex IDs only for genuinely new Canvas objects/edges.
6. Validate JSON Canvas structure and edge referential integrity.
7. Verify that every authority/evidence/transition edge is supported upstream.
8. Commit to Git with auditable lineage.
9. Local Obsidian obtains the update by pull/synchronization.
