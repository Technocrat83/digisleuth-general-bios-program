## PURPOSE

This artifact records the architecture and jurisdictional boundary of the General BIOS Program Registry instantiated in Airtable.

The registry exists to provide operational proprioception over General BIOS scientific objects while preserving the authority of their originating scientific, evidentiary, governance, and lineage surfaces.

The registry is an index of state. It is not a source of scientific truth, authority, admission, execution standing, or promotion.

## PERMITTED OPERATIONS

The registry may:

1. index already-established state;
2. expose current lawful operation;
3. expose next lawful state-changing object when that object has already been established elsewhere;
4. link operational state to Git lineage;
5. support cross-program queries such as frozen, blocked, qualified, unmaterialized, unexecuted, or evidence-zero objects;
6. preserve operational visibility over independent scientific cones.

## PROHIBITED OPERATIONS

- create scientific standing;
- issue admission authority;
- invoke experiments;
